# מסלול שופרסל — מתכנן ביקורים יומי

אפליקציית ווב קטנה לשימוש אישי (נהג/נווט) לתכנון מסלול הביקורים היומי בסניפי שופרסל.
בוחרים עיר → מקבלים רשימת סניפים + מסלול מסודר לפי "הקרוב הבא" (nearest-neighbor) עם כפתורי ניווט.

כולל 340 סניפים ב-101 ערים (דיל, שלי, יוניברס, Be, יש חסד/בשכונה, גוד מרקט, דן דיל, המפיץ, c&c —
סניפי "אקספרס" הוצאו מהאפליקציה. מקור הנתונים המלא, 434 סניפים כולל אקספרס, נשמר ב-`build/branches.raw.json`).

## שימוש

פותחים את **`index.html`** בדפדפן (לחיצה כפולה, או מהנייד).
הקובץ עצמאי לחלוטין — כל הנתונים מוטמעים בתוכו, אין צורך בשרת, באינטרנט או במפתח API.
כפתור "נווט" לכל סניף פותח **Waze**. כפתור "נווט למסלול המלא" פותח **Google Maps**
(ל-Waze אין קישור רשמי למסלול מרובה-תחנות — אין פרמטר waypoints בסכימת ה-URL שלהם,
ואף אין דרך לטעון מראש כמה עצירות, רק הוספה ידנית בתוך ניווט פעיל — לכן זה נשאר על Google Maps
שכן תומך במולטי-סטופ אמיתי).

### פריסה לנייד (מומלץ)
כדי לפתוח מהנייד בקלות אפשר לפרסם ב-GitHub Pages:
`Settings → Pages → Branch: main → /root`, ואז לגשת לכתובת שמתקבלת ולהוסיף למסך הבית.

## איך זה עובד

* **בחירת עיר** — חיפוש/רשימה עם מספר הסניפים בכל עיר.
* **מסלול מסודר** — הסניפים ממוינים nearest-neighbor לפי מרחק אווירי, עם מספור (1,2,3…)
  ואומדן מרחק/זמן בין תחנה לתחנה (מהירות עירונית ממוצעת ~32 קמ"ש).
* **📍 סדר מהמיקום שלי** — מחשב מחדש את הסדר מהמיקום הנוכחי של הנהג (דורש הרשאת מיקום).
* **🧭 נווט (Waze)** — ליד כל סניף, פותח ניווט ב-Waze לנקודה הבודדת.
* **🧭 נווט למסלול המלא (Google Maps)** — קישור אחד עם כל תחנות העיר לפי הסדר (multi-stop).
* **✔️ סמן כבוצע** — ליד כל סניף. סניף מסומן יורד מהמסלול הפעיל ומרשימת העיון, ועובר לרשימה
  נפרדת "✅ סניפים שבוצעו" בתחתית הדף (עם כפתור "↩️ בטל סימון" לשחזור). הסימון נשמר בדפדפן
  של המכשיר (localStorage) — נשאר גם אחרי סגירה ופתיחה מחדש, ועובד בלי אינטרנט.

## עדכון הנתונים

מקור הנתונים: רשימה מלאה (טקסט) לפי אזור → עיר → סוג, עם checksum של מספר סניפים לכל עיר.
צנרת העיבוד (חד-פעמית):

```bash
cd build
python3 parse_full.py     # branches_full.txt -> branches.raw.json (מאמת ספירת סניפים לכל עיר)
python3 geocode2.py       # כתובות -> קואורדינטות (OpenStreetMap, בלי מפתח)
python3 build.py          # מסלולים -> branches.json + index.html
cp index.html branches.json ..   # פרסום
```

* `build.py` מסנן החוצה סוגי סניפים ברשימת `EXCLUDED_TYPES` (כרגע: אקספרס) — לשינוי, ערוך את
  הקבוצה הזו בראש הקובץ. `branches.raw.json` עצמו נשאר מלא (434 סניפים, כולל אקספרס) כמקור אמת.
* `geocode2.py` ממפתח לפי `כתובת|עיר` (לא לפי מס' סניף) כדי לחסוך קריאות חוזרות לאותה כתובת,
  מכבד את מגבלת הקצב של Nominatim (בקשה אחת לשנייה), ושומר תוצאות מצטבר ב-`geocode_cache2.json`
  כך שאפשר לעצור ולהמשיך.
* כתובות מעורפלות (למשל "מתחם ביג") נופלות למיקום ברמת-עיר ומסומנות באפליקציה בהתראת "מיקום משוער".
* להוספת סניפים: הוסף שורות ל-`build/branches_full.txt` בפורמט הקיים (כולל כותרת `**עיר (N)**`
  עם המספר המעודכן — `parse_full.py` יזעק שגיאה אם המספר לא תואם), ואז הרץ שוב את שלושת השלבים.

## קבצים

| קובץ | תיאור |
|------|-------|
| `index.html` | האפליקציה המלאה (עצמאי, עם נתונים מוטמעים) |
| `branches.json` | הנתונים המחושבים (קריא, לעדכון/בדיקה) |
| `build/branches_full.txt` | מקור הנתונים הגולמי (רשימת הסניפים) |
| `build/parse_full.py` | פרסור ואימות מול checksum לכל עיר |
| `build/geocode2.py` | geocoding דרך OpenStreetMap |
| `build/build.py` | חישוב מסלולים + הפקת index.html |
