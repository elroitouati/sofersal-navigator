# 📲 בנייה והתקנה, צעד אחרי צעד

## שלב 1: להתקין את האפליקציה בטלפון (5 דקות, בלי מחשב)

ה-APK נבנה **אוטומטית** ב-GitHub Actions בכל שינוי בקוד, ומתפרסם בדף ה-Releases.

1. בטלפון, פתח: **https://github.com/elroitouati/sofersal-navigator/releases**
2. בגרסה העליונה ("המשימות שלי – גרסה N"), תחת **Assets**, לחץ על הקובץ `school-tasks-N.apk`.
3. כשההורדה מסתיימת, לחץ על הקובץ.
4. אנדרואיד ישאל אם לאפשר התקנה ממקור לא ידוע. לחץ **הגדרות** ← הפעל **"אפשר ממקור זה"** ← חזור ← **התקן**.
5. אם Play Protect מזהיר ("אפליקציה לא מוכרת"), לחץ **פרטים נוספים** ← **התקן בכל זאת**. זה קורה לכל אפליקציה שלא מגיעה מהחנות.
6. פתח את האפליקציה ואשר התראות. בהתחלה יוצגו **נתוני דמה**, כדי שתראה איך הכל עובד.

> **עדכון לגרסה חדשה:** מורידים את ה-APK החדש ומתקינים מעליו. הנתונים נשמרים.

## שלב 2: אמי"ת (2 דקות)

הגדרות ← רשת אמי"ת ← **התחבר**:
1. מזינים שם משתמש וסיסמה ← **המשך**.
2. נפתח האתר. מנווטים: **למידה ← תלמיד**. הסיסמה ממולאת לבד, ורק לוחצים כניסה.
3. בדף המשימות לוחצים **📌 משימות**. אם יש דף ציונים, נכנסים אליו ולוחצים **📌 ציונים**.
4. **סיום**.

אם כתוב "עוד לא זוהו משימות", לחץ **📤 שלח את הדף** ושלח לי את הקובץ (בצ'אט עם Claude). אני אתאים את הפרסר בדיוק לאתר.
עדיף לשלוח: רשימת משימות, דף של משימה אחת, דף ציונים.

## שלב 3: Google Classroom (10 דקות, פעם אחת)

Google דורשת לרשום כל אפליקציה שמבקשת גישה ל-Classroom. זה חינם:

1. היכנס ל-**https://console.cloud.google.com** עם חשבון Google **פרטי** (לא של בית הספר).
2. למעלה: **Select project ← New project**. שם: `school-tasks` ← Create.
3. בחיפוש העליון כתוב **Google Classroom API** ← **Enable**.
4. תפריט ← **APIs & Services ← OAuth consent screen**:
   - User type: **External** ← Create.
   - App name: `המשימות שלי`, ובשדות האימייל: האימייל שלך ← Save and continue (בכל המסכים).
   - בשלב **Test users** ← **Add users** ← הוסף את **חשבון ה-Google של בית הספר** (זה שיש בו את ה-Classroom).
5. **APIs & Services ← Credentials ← Create credentials ← OAuth client ID**:
   - Application type: **Android**
   - Package name: `com.elroi.schooltasks`
   - SHA-1: `5E:8F:16:06:2E:A3:CD:2C:4A:0D:54:78:76:BA:A6:F3:8C:AB:F6:25`
     (טביעת האצבע מופיעה גם בלוג של GitHub Actions, בשלב "Signing certificate fingerprint")
   - Create.
6. באפליקציה: הגדרות ← **התחבר עם Google** ← בחר את חשבון בית הספר ← אשר את ההרשאות (קריאה בלבד).

**אם מופיעה הודעה שבית הספר חוסם:** חלק מבתי הספר לא מאפשרים לתלמידים לחבר אפליקציות חיצוניות. במקרה כזה צריך לבקש מרכז התקשוב לאשר את האפליקציה. האפליקציה תמשיך לעבוד עם אמי"ת בלי Classroom.

## שלב 4: עזרה במשימות (5 דקות, אופציונלי)

1. היכנס ל-**https://console.anthropic.com** ← הרשמה.
2. **Billing**: טען קרדיט (למשל $5, וזה מספיק להמון שאלות).
3. **API Keys ← Create Key** ← העתק.
4. באפליקציה: הגדרות ← עזרה במשימות ← הדבק ← **שמור מפתח**.

## הערות

- **סנכרון ברקע:** בערך כל 30 דקות. אם התראות מגיעות באיחור: הגדרות הטלפון ← אפליקציות ← המשימות שלי ← סוללה ← **ללא הגבלה**.
- **חתימה:** ה-APK חתום במפתח הדיבאג הסטנדרטי של React Native (בגלל זה טביעת ה-SHA-1 קבועה וידועה). זה מספיק לשימוש אישי. אבל **התקן רק APK מהדף של הריפו שלך**, כי APK אחר עם אותה חתימה יכול להתקין את עצמו "כעדכון". אם תרצה מפתח פרטי משלך, תגיד לי ואגדיר את זה (שלב חד-פעמי עם GitHub Secret).

## בנייה ידנית (למתקדמים, לא חובה)

```bash
cd school-app
npm ci
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease
# ← android/app/build/outputs/apk/release/app-release.apk
```

דרוש Node 22, JDK 17 ו-Android SDK. אפשרות אחרת היא EAS: `npx eas-cli build -p android --profile preview` (דורש חשבון Expo).
