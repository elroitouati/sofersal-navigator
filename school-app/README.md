# 📚 המשימות שלי

אפליקציית אנדרואיד שמרכזת במקום אחד את המשימות, הדדליינים, הציונים וההערות מ**רשת אמי"ת** ומ-**Google Classroom**,
שולחת התראות על כל דבר חדש, ונותנת עזרה במשימה (רמז, הסבר או פתרון מלא) בעזרת Claude.

**קריאה בלבד:** האפליקציה לא מגישה, לא ממלאת תשובות ולא משנה שום דבר באתרים. הטופס היחיד שהיא שולחת הוא טופס ההתחברות לאמי"ת.
בדפדפן המובנה של אמי"ת יש סקריפט שומר שחוסם כל שליחת טופס אחר וכל כפתור "הגש/שלח" (`src/sources/amit/webScripts.ts`).

**פרטיות:** אין שרת. הכל נשמר ב-SQLite בטלפון. הסיסמה ומפתח ה-API מוצפנים ב-Android Keystore.
מידע יוצא רק ליעד שלו: הסיסמה לאמי"ת, ה-token ל-Google, ותוכן המשימה ל-Claude (רק כשלוחצים על עזרה).

👉 **איך בונים ומתקינים:** [BUILD.md](BUILD.md)

## מסכים

| מסך | מה יש בו |
|---|---|
| 🏠 ראשי | מונים (פתוחות/היום/באיחור), באיחור, להגשה היום, השבוע, הודעות אחרונות, ציונים אחרונים |
| 📋 משימות | סינון לפי סטטוס, מקור ומקצוע, מיון לפי דדליין, צבע לפי דחיפות |
| משימה | כל הפרטים, הערת המורה, 🤖 עזרה, 🔗 פתיחה באתר המקורי |
| 🤖 עזרה | 💡 רמז (ועוד רמז), 🧭 הסבר החומר, 😩 "לא הצלחתי" (פתרון מלא), ושאלה חופשית |
| 🎯 ציונים | ממוצע לכל מקצוע וממוצע כללי, פירוט בלחיצה |
| ⚙️ הגדרות | חשבונות, נתוני דמה, התראות (3 מתגים), סנכרון, מפתח API, מחיקת הכל |

## מבנה הקוד

```
school-app/
├── src/app/                  # מסכים (expo-router)
│   ├── (tabs)/               # ראשי · משימות · ציונים · הגדרות
│   ├── task/[id].tsx         # דף משימה
│   ├── help/[id].tsx         # עזרה במשימה
│   └── login/amit.tsx        # חיבור לאמי"ת (דפדפן מובנה)
├── src/models/types.ts       # מודל אחיד: Task · Grade · Note
├── src/db/db.ts              # SQLite
├── src/sources/
│   ├── amit/
│   │   ├── selectors.ts      # ⭐ כל מה שתלוי במבנה האתר – רק פה מעדכנים
│   │   ├── parse.ts          # פרסר HTML (קוד טהור, עם בדיקות)
│   │   ├── amitSource.ts     # משיכה + התחברות מחדש אוטומטית
│   │   └── webScripts.ts     # סקריפט שומר + מילוי סיסמה + צילום דף
│   ├── classroom/            # Google Sign-In + Classroom API (readonly)
│   └── mock/                 # נתוני דמה
├── src/sync/                 # מנוע סנכרון, השוואה (diff), משימת רקע
├── src/notify/notify.ts      # התראות + תזכורת יום לפני דדליין
├── src/help/tutor.ts         # העוזר (Claude)
└── tests/                    # בדיקות פרסר ו-diff + fixtures
```

## כשהאתר של אמי"ת משתנה

1. באפליקציה: הגדרות ← אמי"ת ← פתח, מנווטים לדף ולוחצים **📤 שלח את הדף**. ה-HTML נשמר בלי סיסמאות.
2. שמים את הקובץ ב-`tests/fixtures/` ומעדכנים את `src/sources/amit/selectors.ts`.
3. `npm test` לבדיקה, ואחרי push נבנה APK חדש אוטומטית.
